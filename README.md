# ScamShield AI Flutter App

ScamShield AI is your always-on digital bodyguard: a fast, privacy-conscious
mobile protection layer that identifies suspicious calls, messages, and on-screen
content in real time before they can do damage.

Built for high-stakes conversations and modern fraud patterns, the app combines
intelligent detection, instant visual alerts, and user-controlled sensitivity to
deliver enterprise-grade scam defense in your pocket.

## Highlights

- Real-time call and SMS risk analysis
- On-screen scam signal detection with overlay alerts
- Smart sensitivity controls for personalized protection
- Actionable risk feedback designed for non-technical users
- Flutter-based cross-platform architecture with Android-first integrations

## Tech Stack

- Flutter + Dart
- Platform channels and native Android services
- Modular service-oriented app architecture

## Getting Started

### 1) Install dependencies

```bash
flutter pub get
```

### 2) Run the app

```bash
flutter run
```

### 3) Build release APK

```bash
./build_apk.sh
```
